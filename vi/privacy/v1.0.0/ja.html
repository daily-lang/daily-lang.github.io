Daily Viet · プライバシーポリシー

Android / iOS / HarmonyOS 版「Daily Viet」（パッケージ名 com.github.boybeak.daily.lang.vi）に適用されます
バージョン v1.0.0 · 発効日：2026-09-30

一言でいえば：このアプリはあなたの個人情報を収集せず、アカウントも必要ありません。

  • 録音しません。リスニング・音読練習は音声を再生するだけで、マイクを開くことも、あなたの声を取得することもありません。
  • アップロードしません。学習進捗とクイズ記録はお使いのデバイスにのみ保存されます。
  • 共有しません。広告も分析 SDK もなく、第三者があなたのデータを受け取ることはありません。

1.当アプリが処理するデータ

データ処理するか備考

2.アプリが要求するシステム権限

現在のバージョンが要求するのはネットワーク権限（Android の android.permission.INTERNET）のみで、将来のコンテンツ更新に備えたものです。それ以外に、カメラ、マイク、位置情報、連絡先、フォトライブラリ、通知などのセンシティブな権限は一切要求しません。クリップボードやデバイス識別子も同様に読み取りません。

3.デバイス上に保存されるデータ

  • 保存されるもの：学習済みの項目と直近の学習日時、レッスン末の小テストの設問ごとの正誤記録、表示言語や学習設定（1 日の目標など）。
  • 保存場所：お使いのデバイス上のアプリのプライベートストレージ内のみで、いかなるサーバーにもアップロードされません。
  • 削除方法：アプリをアンインストールするか、システム設定の「アプリデータを消去」を実行すると、これらの記録は削除されます。アプリはクラウド同期を提供していないため、削除された記録は復元できません。
  • あなたの特定には使われません：これらの記録が示すのは「このデバイス上での学習状況」であり、あなた個人の身元を指し示す情報は一切含まれていません。

4.マイクと音声

  • 現在のバージョンはマイク権限を要求せず、音声の録音やアップロードも行いません。アプリの権限一覧に録音に関する権限は存在しません。
  • リスニング・音読練習は音声を再生するだけです。練習画面で再生されるのはアプリに同梱された学習音声であり、マイクを開いたり、あなたの声を取得したりすることはありません。
  • リピート練習の録音や発音採点は、現在のバージョンの機能範囲外です。将来のバージョンで追加される場合は、そのバージョンの公開前に本ポリシーを更新し、それまではマイク権限を要求しません。

5.分析、クラッシュとログ

  • アプリ内のイベントマーカー（対象言語の異なるアプリを区別するためのもの）は、現在デバイス内のローカルログにのみ書き込まれ、開発時のトラブルシューティングに使用され、アップロードされません。
  • 現在のバージョンは分析、広告、クラッシュレポートのいかなるサービスも組み込んでいません。
  • 将来これらのサービスが追加される場合、本ポリシーもあわせて更新され、更新後のバージョンで収集範囲が説明されます。

6.第三者コンポーネントとデータ共有

  • アプリはあなたのデータを第三者に販売、貸与、共有しません（実際のところ、共有できるようなデータ自体を保有していません）。
  • アプリは広告、プロファイリング、データ分析系の SDK を一切組み込んでいません。
  • 画面描画と音声再生にはオープンソースコンポーネントを使用していますが、これらのコンポーネントはアプリ内でインターフェースの描画と同梱音声の再生のみを行い、あなたのデータを収集しません。
  • アプリに同梱される学習コンテンツと音声は当方が制作したものであり、あなたの個人情報には関係しません。

7.未成年者について

本アプリは子ども向けに設計されたものではなく、子どもから個人情報を意図的に収集することもありません。本アプリは個人情報を収集せずアカウントも不要であるため、保護者の指導のもとで子どもが利用しても、それによって個人データが生成されることはありません。

8.本ポリシーの変更とお問い合わせ

本ポリシーに変更がある場合、新バージョンのリリースと同時にこのページを更新し、上記の発効日も更新します。データの取り扱いに関わる重要な変更については、アプリ内で目立つ形でお知らせします。
